======================================
Chrome Web Store 擴充功能說明 v2.3
======================================

【簡短描述】
強化 NYCU E3：作業倒數、公告信件、成績、教材下載、雙語介面、AI 摘要與每日總覽、可自訂截止提醒。

【詳細描述】
NYCU E3 Helper 是為陽明交通大學學生設計的 E3 輔助工具，可在瀏覽器側邊欄集中處理課程資訊與常用操作。

========== 主要功能 ==========

📝 作業管理
・同步 E3 作業與截止時間，顯示倒數與課程名稱
・支援手動新增、編輯、刪除與繳交狀態管理
・快速前往 E3 作業頁面

📢 公告與信件
・整合各課程公告與 dcpcmail 信件
・支援未讀狀態、篩選與內容預覽
・定時同步只會重用已開啟的 E3 分頁；E3 未開啟時會跳過，不會背景打開登入頁

📊 成績與教材
・查詢課程成績與項目資訊
・掃描課程教材，支援個別下載與 ZIP 批次下載

🌐 介面與外觀
・繁體中文 / English 介面
・Light / Dark / System 外觀設定

🤖 摘要、每日總覽與翻譯（選配）
・AI 摘要可選 Gemini 或 OpenAI，使用者自行提供對應 API Key
・今日總覽可整理當日公告與信件，並保留來源連結與本機快取
・中英翻譯使用 Google Translate，不需要 Gemini / OpenAI API Key
・AI 功能可完全停用

🔔 通知與截止提醒
・可開關桌面通知、更新通知與即時 / 每日通知方式
・可設定多個作業截止提醒時距
・背景佇列會避免重複通知，並略過已繳交、已移除、已變更或已過期的作業提醒

========== 隱私與安全 ==========

・課程資料、設定、通知狀態與 API Key 儲存在瀏覽器本機
・不販售或上傳使用者資料到本專案自己的伺服器
・E3 資料只向 NYCU E3 官方 HTTPS 主機存取
・AI 摘要啟用時，必要文字會傳送至使用者選擇的 Gemini 或 OpenAI
・翻譯時，待翻譯文字會傳送至 Google Translate
・OpenAI Responses API 使用 store:false
・專案開源，可自行檢視程式碼

========== 第三方服務 ==========

・NYCU E3：e3.nycu.edu.tw、e3p.nycu.edu.tw（核心功能）
・Google Gemini：generativelanguage.googleapis.com（AI 摘要，選配）
・OpenAI：api.openai.com（AI 摘要，選配）
・Google Translate：translate.googleapis.com（翻譯功能）

========== v2.3 重點 ==========

・新增繁中 / 英文介面與 Light / Dark / System 外觀
・新增 Gemini / OpenAI 可選摘要與每日總覽
・新增可自訂桌面通知與多組截止提醒
・定時公告 / 信件同步不再自行開啟 E3 背景分頁
・加強 E3 URL 驗證、內容 HTML 清理與背景日誌一致性
